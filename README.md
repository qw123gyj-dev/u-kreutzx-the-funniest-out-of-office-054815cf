# The Funniest Out-of-Office

One line of an out-of-office auto-reply, under 140 characters, judged head to head by an AI judge on funniness. `main.ts` (Node 22, stdlib only, no network) writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it is a single non-blank line within the 140-character limit, reads it back and verifies the bytes match.

> "I'm out of office until the 12th. My auto-reply is doing all my work this week, and it's already asked for a raise."
